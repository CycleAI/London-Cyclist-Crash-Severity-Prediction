## How to use this archive

Start with the consolidated task folders under `workflows/`; consult these variants only when their input policy or method matches the investigation. Each file is inventoried by purpose. Names such as old `NNForAccidents2` are mapped to descriptive replacements in the audit manifest.

No final chronology can be inferred from notebook metadata or names. Historical outputs remain unvalidated. Environment/configuration varies by file and dependencies can conflict; follow the running guide and isolate experiments. Exact duplicates are recoverable from Git history instead of being stored again here.
