# Data

This folder contains data files used by the pipeline notebooks. One file is hosted externally due to file size constraints. This README describes each file, which notebook produces it, and how to obtain it.

---

## Files Included in This Repository

| File | Description |
|---|---|
| `gpt_trueskill_rankings_200k_20_06_26.csv` | GPT-5.2 TrueSkill rankings built from the full 200k extended vote set. Used as the prediction target in Stage 2. Columns: image_name, gpt_mu, gpt_sigma, gpt_ts_score, rank_gpt. |
| `gpt_trueskill_rankings_final_20_06_26.csv` | GPT-5.2 TrueSkill rankings built from the 25k validated vote set. Used in Stage 1 agreement analysis. Same column structure as above. |
| `gpt52_votes_25k_final.csv` | GPT-5.2 validated vote set. 25,560 votes on the same pairs as the human poll. Columns: user_id, image_name1, image_name2, vote, voting_time, model_id, reason. |
| `gpt52_votes_100k_20_06_26.csv` | GPT-5.2 extended vote set (first batch, approximately 100k votes). Part of the 200k extended ranking pipeline. Same column structure as above. |
| `gpt52_votes_100k_2_20_06_26.csv` | GPT-5.2 extended vote set (second batch, approximately 100k votes). Part of the 200k extended ranking pipeline. Same column structure as above. |
| `human_trueskill_rankings_final_20_06_26.csv` | Human TrueSkill rankings after behaviour-based filtering. 17,246 images. Columns: image_name, human_mu, human_sigma, human_ts_score, rank_human. |
| `human_votes_05_06_26.csv` | Raw crowdsourced pairwise votes from the perception poll. 25,571 votes from 524 participants before filtering. Columns: user_id, image_name1, image_name2, vote, voting_time. |
| `metadata_images_mapping.csv` | Street-level image coordinates with GPS correction applied. Maps each image blob name to its corrected latitude and longitude. |

## Image Data (Azure Blob Storage)

Street-level images and their segmentation outputs are stored in Azure Blob Storage and are not included in this repository.

| Container path | Description |
|---|---|
| `london/training/training/Images/` | Google Street View images. Filename format: `{point_id}_{heading}.jpg`. |
| `london/PanopticSegmentation/json/` | Panoptic segmentation JSONs produced by Mask2Former (Mapillary Vistas). One JSON per image. |
| `london/PanopticSegmentation/masks/` | Panoptic segmentation mask PNGs. One mask per image. |
| `london/YoloV10/` | YOLOv10 object detection outputs. One TXT file per image in YOLO format. |

Access to Azure Blob Storage requires credentials. Set the `AZURE_CONN_STR` environment variable as described in the main README before running notebooks 01, 02 or 10.
