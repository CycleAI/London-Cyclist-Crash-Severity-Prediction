# Public release and data availability

This public repository was prepared on 9 November 2026 from a private research archive.
All retained commits have been sanitized. Raw perception-poll votes, participant
identifiers, embedded access tokens, private manuscript/source links and personal
machine paths are excluded. Notebook outputs and execution metadata have been
cleared throughout history. Private author email addresses use GitHub no-reply
addresses; research attribution is retained.

Aggregate image-level human TrueSkill rankings and synthetic model votes may be
shared; these are distinct from participant-level human poll records. Public
police-recorded STATS19 collision-derived tables in Paper 2 are also distinct from
the perception-poll participants.

## Running the code

- Supply your own credentials through environment variables or ignored local
  configuration. Placeholder resource names and paths require configuration.
- Raw human poll votes are restricted inputs and are not included. Analyses that
  read those votes cannot be reproduced from this public repository alone.
- Saved figures, result tables and fitted models are retained where supplied.
  Clearing notebook outputs does not mean models were retrained or results rerun.
- Other missing source data, imagery and intermediate artifacts are described in
  the data and notebook guides. There is no claim of complete end-to-end reproduction.
- Repository history has changed. Use a fresh clone of this public release;
  merging an older private clone can reintroduce removed material.

Before committing new files, check notebook outputs, archives, local configuration
and data exports for credentials or participant identifiers. Ignore rules do not
remove files already tracked by Git.
